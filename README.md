# Pərakəndə Satış və Maliyyə Analizi (Retail Sales Data Analysis)

##  Layihə Haqqında
Bu layihədə 10 milyondan çox tranzaksiya sətirinə sahib böyük həcmli pərakəndə satış datası **R** dili vasitəsilə təmizlənmiş, emal olunmuş və geniş mənfəətlilik analizi aparılmışdır.

##  İstifadələr və Alətlər
* **Proqramlaşdırma Dili:** R
* **Kitabxanalar:** `dplyr`, `data.table`, `ggplot2`, `plotly`, `stringr`, `RMarkdown`
* **Nəticə Faylları:** RMarkdown HTML hesabatı və PDF təqdimat

##  Esas Analiz İstiqamətləri və Nəticələr
* **Data Cleaning & Structuring:** 10M+ sətir məlumat `data.table` və `dplyr` alətləri ilə təmizlənmiş, unifikasiya edilmiş və struktura salınmışdır.
* **Exploratory Data Analysis (EDA):** Şirkətin gəlir strukturu, müştəri səbət ölçüləri, top 10 məhsul/POS və həftəlik satış dinamikası (günlər üzrə satış pikləri) təhlil edilmişdir.
* **Anomaliya və Boşluq Analizi:** Mənfəət marjasındakı kütləvi boşluqlar (NA göstəriciləri), kassa/sistem xətaları və zərər edən məhsul kateqoriyaları müəyyən edilmişdir.
